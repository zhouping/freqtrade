# Log 目录说明

## 用途

Log 文件用来记录所有针对 Freqtrade 项目的操作。

## 记录内容

- **修改代码**：
  - 具体文件名
  - 第几行
  - 增加/删除/修改内容
  - 操作原因

## 文件名格式

```
日期.log
```

格式：`YYYY-MM-DD.log`

示例：`2026-04-15.log`

## Log 内容格式

```
时间 - 操作内容
```

- **时间**：HH:MM:SS 格式
- **操作内容**：描述具体操作

### 示例
```
20:30 - 修改 freqtrade/strategy/macd_rsi.py 第 45 行，将 RSI 阈值从 30 改为 35（原因：降低假信号）

20:45 - 新增文件 freqtrade/config/new_strategy.py（原因：测试新策略）
```

## 记录分隔

每条记录占一行，记录之间以**空行**分割。
