# 回测结果目录说明

## 目录结构

每次回测创建子目录，命名格式为：

```
策略名-交易品种-时间周期-回测日期-回测时间
```

### 命名规则
- **策略名**：使用的交易策略名称（如 MACD_RSI_BB、SMA_Cross 等）
- **交易品种**：交易的标的（如 BTC_USDT、ETH_USDT 等）
- **时间周期**：K线时间周期（如 1m、5m、15m、1h、4h、1d 等）
- **回测日期**：回测日期，格式 YYYY-MM-DD
- **回测时间**：回测时间，格式 HH-MM（或 HHMM）

### 示例
```
MACD_RSI_BB-BTC_USDT-1h-2026-04-15-20-30/
SMA_Crossover-ETH_USDT-15m-2026-04-14-10-00/
```

## 子目录内容

每个回测子目录下保存以下文件：

### 交易明细文件
- `trades.csv` - 交易记录明细（包含每笔交易的日期、时间、品种、方向、买入价、卖出价、数量、盈亏等）
- `trades.json` - 交易记录明细（JSON 格式）

### 回测结果文件
- `result.json` - 回测结果汇总（包含成功率、收益率、最大回撤、夏普比率等数据）
- `result.md` - 回测结果说明文档
- `equity_curve.csv` - 权益曲线数据
- `metrics.json` - 各种性能指标数据

### 配置说明文件
- `config.json` - 回测使用的策略参数配置
- `config.yaml` - 回测使用的完整配置

## 回测结果指标

result.json 中应包含但不限于以下指标：

- **成功率** - 盈利交易数 / 总交易数
- **总收益率** - (最终权益 - 初始权益) / 初始权益
- **夏普比率**
- **最大回撤**
- **盈亏比** - 平均盈利 / 平均亏损
- **交易次数**
- **平均持仓时间**
