## 待解决问题

### 寻找可稳定盈利的策略

核心目标：**权益曲线以一定角度稳定向上**（不论牛市/熊市/震荡市）

#### 测试标准（定性描述）

| 指标 | 及格 | 良好 | 优秀 |
|------|------|------|------|
| **权益曲线** | 向上，但有较大回撤 | 稳定向上 | 平滑稳定向上 |
| **夏普比率** | > 1.0 | > 1.5 | > 2.0 |
| **胜率** | > 40% | > 45% | > 50% |
| **盈亏比** | > 1.2 | > 1.5 | > 2.0 |
| **最大回撤** | < 30% | < 20% | < 15% |
| **一致性** | 有月份亏损 | 多数月份盈利 | 每月都盈利 |

#### 核心指标解释

- **夏普比率 (Sharpe)**：每承担1单位风险获得的超额收益，>1.0 表示风险调整后收益优于无风险资产
- **卡尔马比率 (Calmar)**：年化收益率 / 最大回撤，>1.0 表示年化收益覆盖最大回撤
- **一致性**：逐月检查是否有连续亏损月份（体现策略稳定性）

#### 测试步骤

1. **批量筛选**：用 2025 数据回测所有策略，按收益率排序
2. **参数优化**：对 Top 5 策略进行 hyperopt 优化
3. **稳定性验证**：用不同时间窗口测试（如 2024年数据验证）
4. **实盘模拟**：dry-run 模式验证
