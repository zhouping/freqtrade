# 回测结果目录说明

## 目录结构

每次回测创建子目录，命名格式为：

```
策略名-交易品种-时间周期-回测日期-回测时间
```

生成回测结果文件时，注意：

1、CSV格式文件中的中文应使用GBK
2、回测交易明细文件名命名规则：策略名_交易明细_日期时间.csv
3、回测结果文件生成规则：
每次回测在 /home/kali/Project/freqtrade/user_data/backtest_results/ 中新建一个存放回测结果的文件夹：
文件夹命名规则：策略名-交易所-交易品种-时间周期-当前日期-当前时间
- **策略名**：使用的交易策略名称（如 MACD_RSI_BB、SMA_Cross 等）
- **交易所**：执行回测所获取元数据的交易所（Binance\OKX\Gate\HTX\Kraken\Bybit\BitMart\Bitget\BingX\Kucoin）
- **交易品种**：交易的标的（如 BTC_USDT、ETH_USDT 等）
- **时间周期**：K线时间周期（如 1m、5m、15m、1h、4h、1d 等）
- **当前日期**：回测日期，格式 YYMMDD
- **当前时间**：回测时间，格式 HHMMSS（或 HHMM）
### 示例
```
MACD_RSI_BB-Gate-BTC_USDT-1h-202604152030/

```

## 子目录内容

每个回测子目录下保存以下文件：

### 交易明细文件
- `trades.csv` - 交易记录明细
包含内容：每笔交易的日期、时间、方向(多、空)、成交价、数量、盈亏、操作（开仓、止损、止盈）

### 回测结果文件
- `result.json` - 回测结果汇总
应包含但不限于以下指标：
- **成功率** - 盈利交易数 / 总交易数
- **总收益率** - (最终权益 - 初始权益) / 初始权益
- **夏普比率**
- **最大回撤**
- **盈亏比** - 平均盈利 / 平均亏损
- **交易次数**
- **平均持仓时间**

### 配置说明文件
- `strategy_parameters.json` - 回测使用的策略参数配置
- `config.yaml` - 回测使用的完整配置


***关于优化操作的规范***
1、子目录名、文件名要求基本和以上回测类似
2、优化结果同样保存在/home/kali/Project/freqtrade/user_data/backtest_results/目录下，**新建优化目录**，目录名包含操作日期时间（以及结果文件名遵循**操作规范**）
3、和回测不同的结果文件以文本形式，内容清晰有条理！
4、freqtrade 自行生成的结果文件 ，即/home/kali/Project/freqtrade/user_data/hyperopt_results/ 目录中的文件无需删除，只要把其中有意义的内容总结到你的 *新建优化目录*中。
