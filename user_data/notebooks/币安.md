# Binance 币安回测指南

> 本文档整理 Binance 主网现货/期货回测配置与经验

---

## 核心原则

| 原则 | 说明 |
|------|------|
| **现货模式 + 现货数据** | 正确 ✓ |
| **期货模式 + 期货数据** | 正确 ✓ |
| **现货模式 + 期货数据** | 错误 ✗ 严禁使用！ |
| **期货模式 + 现货数据** | 错误 ✗ 严禁使用！ |

---

## 两种模式对比

|| 现货 (Spot) | 期货 (Futures) |
|------|-------------|----------------|
| `trading_mode` | `"spot"` | `"futures"` |
| `margin_mode` | 无 | `"isolated"` |
| `pair_whitelist` | `["BTC/USDT"]` | `["BTC/USDT:USDT"]` |
| 数据目录 | `datadir/` | `datadir/futures/` |
| 数据文件名 | `BTC_USDT-5m.feather` | `BTCUSDT_USDT-5m-futures.feather` |
| 交易对格式 | `BTC/USDT` (有斜杠) | `BTC/USDT:USDT` (base/quote/margin) |
| 代理 | **需要** | **需要** |

## 代理配置

### 为什么需要代理？

Binance API (`api.binance.com`) 在中国大陆无法直接访问，需要通过代理连接。

### 当前代理配置

| 项目 | 配置 |
|------|------|
| 代理软件 | Clash Verge |
| 代理端口 | 7897 (mixed port) |
| 代理类型 | HTTP |

### 测试代理连通性

```bash
# 测试 Binance API 连通性
curl --max-time 5 --proxy http://127.0.0.1:7897 https://api.binance.com/api/v3/exchangeInfo
```

成功输出示例：
```json
{
  "timezone": "UTC",
  "serverTime": 1745301234567,
  "symbols": [...]
}
```

### 环境变量方式

```bash
export http_proxy=http://127.0.0.1:7897
export https_proxy=http://127.0.0.1:7897
```

freqtrade 配置中需要添加 `"aiohttp_trust_env": true`。

### 节点切换

```bash
/home/kali/Project/clash-verge-rev/clash-ctl list
/home/kali/Project/clash-verge-rev/clash-ctl switch "GLOBAL" "🇺🇲 美国节点"
```

## 数据获取方式

### 方式1: Binance Vision S3（推荐）

**不需要代理！** 直接从 AWS S3 下载。

```bash
python /home/kali/Project/freqtrade/user_data/scripts/download_binance_data.py \
  --mode both \
  --years 2024 2025 \
  --intervals 1m 5m 30m 1h
```

### 方式2: freqtrade 直连下载（需要代理）

```bash
export http_proxy=http://127.0.0.1:7897
export https_proxy=http://127.0.0.1:7897

# 现货
freqtrade download-data \
  --config user_data/config_binance_spot.json \
  --pairs BTC/USDT \
  --timeframes 5m \
  --timerange 20250101-20251231

# 期货
freqtrade download-data \
  --config user_data/config_binance_futures.json \
  --pairs BTC/USDT:USDT \
  --timeframes 5m \
  --timerange 20250101-20251231
```

## 常见问题

### Q1: "BTC/USDT is not tradable with Freqtrade"

**原因**: freqtrade 加载了现货交易对，但配置了期货模式。

**解决**: 检查配置中的 `trading_mode` 和 `pair_whitelist` 是否匹配数据目录。

### Q2: "No history found"

**原因**: 数据文件不在正确目录。

**解决**: 
- 现货数据 → `user_data/data/BTC_USDT-5m.feather`
- 期货数据 → `user_data/data/futures/BTCUSDT_USDT-5m-futures.feather`

### Q3: 连接超时

**原因**: 代理无法连接 Binance API。

**解决**: 切换代理节点后重试。
