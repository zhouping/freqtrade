# Binance 币安回测指南

> 本文档整理 Binance 主网现货/期货回测配置与经验

---

## 核心原则

| 原则 | 说明 |
|------|------|
| **现货模式 + 现货数据** | 正确 ✓ |
| **期货模式 + 期货数据** | 正确 ✓ |
| **现货模式 + 期货数据** | 错误 ✗ 严禁使用！ |
| **期货模式 + 现货数据** | 错误 ✗ 严禁使用！ |

---

## 两种模式对比

|| 现货 (Spot) | 期货 (Futures) |
|------|-------------|----------------|
| `trading_mode` | `"spot"` | `"futures"` |
| `margin_mode` | 无 | `"isolated"` |
| `pair_whitelist` | `["BTC/USDT"]` | `["BTC/USDT:USDT"]` |
| 数据目录 | `datadir/` | `datadir/futures/` |
| 数据文件名 | `BTC_USDT-5m.feather` | `BTCUSDT_USDT-5m-futures.feather` |
| 交易对格式 | `BTC/USDT` (有斜杠) | `BTC/USDT:USDT` (base/quote/margin) |
| 代理 | **需要** | **需要** |

## 代理配置

### 为什么需要代理？

Binance API (`api.binance.com`) 在中国大陆无法直接访问，需要通过代理连接。

### 当前代理配置

| 项目 | 配置 |
|------|------|
| 代理软件 | Clash Verge |
| 代理端口 | 7897 (mixed port) |
| 代理格式 | `socks5h://` (SOCKS5 + DNS远程解析) ⚠️ |
| 配置文件 | `~/.zshrc` |

### 环境变量配置（2026-04-23 更新）

```bash
# ⚠️ 必须使用 socks5h:// 格式，不是 http://
export https_proxy=socks5h://127.0.0.1:7897
export http_proxy=socks5h://127.0.0.1:7897
export all_proxy=socks5h://127.0.0.1:7897
```

### ccxt_config 配置（关键！）

```json
"ccxt_config": {
  "enableRateLimit": true,
  "aiohttp_trust_env": true,
  "requests_trust_env": true  // ⚠️ 必须添加！ccxt 同步模式用 requests
}
```

**关键发现（2026-04-23）：**
- ccxt 同步模式使用 `requests` 库，需要 `requests_trust_env: true`
- ccxt 异步模式使用 `aiohttp` 库，需要 `aiohttp_trust_env: true`
- freqtrade 回测两者都用到，必须同时设置

### 节点切换

#### ⚠️ 如果切换失败
先将 Clash Verge 的代理模式改为**全局/GLOBAL**，再执行自动切换。

#### 方式1: clash-ctl（推荐）

```bash
/home/kali/Project/clash-verge-rev/clash-ctl list
/home/kali/Project/clash-verge-rev/clash-ctl switch "GLOBAL" "🇺🇲 美国节点"
```

#### 方式2: clash_verge_cli.py（自动切换）

```bash
# 位置
/home/kali/Project/freqtrade/user_data/scripts/BinanceConnection/clash_verge_cli.py

# 自动找到能连 Binance 的节点并切换
./clash_verge_cli.py binance -n 10 --auto-switch GLOBAL
```

#### ⚠️ 如果切换失败
先将 Clash Verge 的代理模式改为**全局/GLOBAL**，再执行自动切换。

## 现货回测配置

### 配置文件: config_binance_spot.json

```json
{
  "max_open_trades": 3,
  "stake_currency": "USDT",
  "stake_amount": 1000,
  "dry_run": true,
  "dry_run_wallet": 10000,
  "unfilledtimeout": {"entry": 10, "exit": 10, "unit": "minutes"},
  "entry_pricing": {"price_side": "same", "use_order_book": true, "order_book_depth": "0.01%"},
  "exit_pricing": {"price_side": "same", "use_order_book": true, "order_book_depth": "0.01%"},
  "exchange": {
    "name": "binance",
    "key": "",
    "secret": "",
    "ccxt_config": {
      "enableRateLimit": true,
      "aiohttp_trust_env": true,
      "requests_trust_env": true  // ⚠️ 必须添加！
    },
    "pair_whitelist": ["BTC/USDT"],
    "trading_mode": "spot"
  },
  "pairlists": [{"method": "StaticPairList"}],
  "timeframe": "5m"
}
```

### 回测命令

```bash
cd /home/kali/Project/freqtrade

# 必须使用 socks5h:// 格式
export https_proxy=socks5h://127.0.0.1:7897
export http_proxy=socks5h://127.0.0.1:7897
export all_proxy=socks5h://127.0.0.1:7897

# 现货回测
freqtrade backtesting \
  --config user_data/config_binance_spot.json \
  --strategy GodStra \
  --strategy-path user_data/strategies \
  --data-format-ohlcv feather \
  --datadir user_data/data/binance \
  --pairs BTC/USDT \
  --timeframe 5m \
  --timerange 20251225-20260101 \
  --dry-run-wallet 10000

# 期货回测
freqtrade backtesting \
  --config user_data/config_binance_futures.json \
  --strategy GodStra \
  --strategy-path user_data/strategies \
  --data-format-ohlcv feather \
  --datadir user_data/data/binance \
  --pairs BTC/USDT:USDT \
  --timeframe 5m \
  --timerange 20251225-20260101 \
  --dry-run-wallet 10000
```

## 期货回测配置

```json
{
  "max_open_trades": 3,
  "stake_currency": "USDT",
  "stake_amount": 1000,
  "dry_run": true,
  "dry_run_wallet": 10000,
  "trading_mode": "futures",
  "margin_mode": "isolated",
  "unfilledtimeout": {"entry": 10, "exit": 10, "unit": "minutes"},
  "entry_pricing": {"price_side": "same", "use_order_book": true, "order_book_depth": "0.01%"},
  "exit_pricing": {"price_side": "same", "use_order_book": true, "order_book_depth": "0.01%"},
  "exchange": {
    "name": "binance",
    "key": "",
    "secret": "",
    "ccxt_config": {
      "enableRateLimit": true,
      "aiohttp_trust_env": true,
      "requests_trust_env": true  // ⚠️ 必须添加！
    },
    "pair_whitelist": ["BTC/USDT:USDT"],  // ⚠️ 期货三段式格式
    "trading_mode": "futures",
    "futures_trading_mode": "perpetual"
  },
  "pairlists": [{"method": "StaticPairList"}],
  "timeframe": "5m"
}
```

**关键配置点（2026-04-23 更新）：**
1. `trading_mode: "futures"` — **顶层配置**
2. `margin_mode: "isolated"` — **顶层配置**
3. `pair_whitelist: ["BTC/USDT:USDT"]` — 三段式交易对格式
4. `requests_trust_env: true` — ⚠️ 必须添加！

### 回测命令

```bash
cd /home/kali/Project/freqtrade
```

## 数据文件格式

### 目录结构

| 模式 | 目录 | 示例 |
|------|------|------|
| 现货 | `user_data/data/binance/` | `BTC_USDT-5m.feather` |
| 期货 | `user_data/data/binance/futures/` | `BTC_USDT_USDT-5m-futures.feather` |

### 文件名规范

| 数据类型 | 格式 | 示例 | 备注 |
|----------|------|------|------|
| 现货 | `{base}_{quote}-{timeframe}.feather` | `BTC_USDT-5m.feather` | 标准格式 |
| 期货 | `{base}_{quote}_{margin}-{timeframe}-futures.feather` | `BTC_USDT_USDT-5m-futures.feather` | ⚠️ 中间是 `_USDT_` |
| 带年份 | ❌ 不支持 | `BTC_USDT-5m-2024.feather` | freqtrade 不支持年份 |

### 数据文件重命名（2026-04-23）

下载的期货数据原始文件名：`BTCUSDT_USDT-5m-futures.feather`

freqtrade 内部格式：`BTC_USDT_USDT-5m-futures.feather`

需要重命名：
```bash
mv BTCUSDT_USDT-5m-futures.feather BTC_USDT_USDT-5m-futures.feather
```

## 常见问题

### Q1: "BTC/USDT is not tradable with Freqtrade"

**原因**: freqtrade 加载了现货交易对，但配置了期货模式。

**解决**: 检查配置中的 `trading_mode` 和 `pair_whitelist` 是否匹配数据目录。

### Q2: "No history found"

**原因**: 数据文件不在正确目录。

**解决**: 
- 现货数据 → `user_data/data/BTC_USDT-5m.feather`
- 期货数据 → `user_data/data/futures/BTCUSDT_USDT-5m-futures.feather`

### Q3: 连接超时

**原因**: 代理无法连接 Binance API。

**解决**: 切换代理节点后重试。
