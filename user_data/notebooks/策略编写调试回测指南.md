## 2. IStrategy 基类与策略结构

### 2.1 策略目录和文件结构

```
Project/freqtrade/
├─ freqtrade/
│  ├─ strategy/          ← 存放所有策略源码
│  │   ├─ __init__.py
│  │   ├─ interface.py   ← IStrategy 抽象基类
│  │   └─ sample_strategy.py (示例模板)
│  └─ docs/              ← 官方文档，含 strategy-*.md
└─ user_data/
   ├─ strategies/        ← 自定义策略存放位置（推荐）
   ├─ data/
   └─ logs/
```

### 2.2 IStrategy 基类（核心）

所有自定义策略必须继承 `freqtrade.strategy.IStrategy`（位于 `freqtrade/strategy/interface.py`）：

| 属性/方法 | 说明 |
|---|---|
| `timeframe` | 使用的时间周期，例如 `'5m'`、`'1h'` |
| `stoploss` | 固定止损比例，负数，如 `-0.10`（亏损 10%） |
| `minimal_roi` | ROI 字典，如 `{"0": 0.02}` 表示盈利 2% 即平仓 |
| `trailing_stop`（可选）| 启用追踪止损 |
| `trailing_stop_positive`（可选）| 追踪止损正偏移 |
| `startup_candle_count` | 策略启动所需历史蜡烛数 |
| `populate_indicators(self, dataframe, metadata)` | 添加指标列，返回 DataFrame |
| `populate_entry_trend(self, dataframe, metadata)` | 生成 `enter_long`/`enter_short` 信号 |
| `populate_exit_trend(self, dataframe, metadata)` | 生成 `exit_long`/`exit_short` 信号 |
| 其它回调（可选）| `custom_trade_info`, `confirm_trade_entry`, `confirm_trade_exit`, `adjust_trade_position` |

> **注意**：在 `populate_*` 方法中必须 **返回 dataframe**，禁止修改 `open`、`high`、`low`、`close`、`volume` 列结构。

### 2.3 创建新策略

```bash
# CLI 生成模板
freqtrade new-strategy --strategy MyStrategy          # 基础模板
freqtrade new-strategy --strategy MyStrategy --template minimal   # 空白模板
freqtrade new-strategy --strategy MyStrategy --template advanced  # 包含示例指标

# 手动复制示例
cp freqtrade/templates/sample_strategy.py user_data/strategies/MyStrategy.py
```

### 2.4 最小策略代码示例

```python
from freqtrade.strategy import IStrategy
from pandas import DataFrame
import talib.abstract as ta

class MyStrategy(IStrategy):
    timeframe = '15m'
    stoploss = -0.10          # 亏损 10% 时强制平仓
    minimal_roi = {"0": 0.01}  # 盈利 1% 即平仓
    startup_candle_count = 50     # 策略需要 50 根蜡烛预热

    def populate_indicators(self, dataframe: DataFrame, metadata: dict) -> DataFrame:
        dataframe['rsi'] = ta.RSI(dataframe, timeperiod=14)
        dataframe['ema20'] = ta.EMA(dataframe, timeperiod=20)
        return dataframe

    def populate_entry_trend(self, dataframe: DataFrame, metadata: dict) -> DataFrame:
        dataframe.loc[
            (dataframe['rsi'] < 30) & (dataframe['close'] > dataframe['ema20']),
            'enter_long'] = 1
        return dataframe

    def populate_exit_trend(self, dataframe: DataFrame, metadata: dict) -> DataFrame:
        dataframe.loc[
            (dataframe['rsi'] > 70) | (dataframe['close'] < dataframe['ema20']),
            'exit_long'] = 1
        return dataframe
```

**关键点**：
- 使用 `dataframe.loc[condition, 'column'] = 1`，避免 pandas 向量化错误
- 所有指标列在 `populate_indicators` 中创建，后续函数直接引用

## 3. 常用技术指标

Freqtrade 集成三大技术指标库：

| 库 | 导入方式 |
|---|---------|
| **ta-lib** | `import talib.abstract as ta` |
| **pandas-ta** | `import pandas_ta as pta` |
| **technical** | `from technical import indicator` |

常用指标速查：

| 指标 | 典型参数 | 示例代码 |
|---|---|---|
| RSI | `timeperiod=14` | `dataframe['rsi'] = ta.RSI(dataframe, timeperiod=14)` |
| EMA | `timeperiod=n` | `dataframe['ema20'] = ta.EMA(dataframe, timeperiod=20)` |
| SMA | `timeperiod=n` | `dataframe['sma50'] = ta.SMA(dataframe, timeperiod=50)` |
| MACD | `fastperiod=12, slowperiod=26, signalperiod=9` | `macd = ta.MACD(dataframe); dataframe['macd'] = macd['macd']` |
| Bollinger Bands | `nbdevup=2, nbdevdn=2, timeperiod=20` | `bb = ta.BBANDS(dataframe); dataframe['bb_lower'] = bb['lowerband']` |
| ADX | `timeperiod=14` | `dataframe['adx'] = ta.ADX(dataframe)` |
| ATR | `timeperiod=14` | `dataframe['atr'] = ta.ATR(dataframe, timeperiod=14)` |

> **性能提示**：仅保留实际使用的指标，避免在 `populate_indicators` 中一次性加载全部指标，会显著增加 CPU 与内存开销。

## 4. 入场与出场信号

### 4.1 信号列约定

- **enter_long** / **enter_short**：值为 `1` 表示产生对应方向的买入信号
- **exit_long** / **exit_short**：值为 `1` 表示产生对应方向的卖出信号
- 信号列必须始终存在（即使只做多）

### 4.2 常见写法

```python
# 多头入场：RSI 超卖且收盘价在 EMA 上方
condition = (dataframe['rsi'] < 30) & (dataframe['close'] > dataframe['ema20'])
dataframe.loc[condition, 'enter_long'] = 1
```

### 4.3 防止碰撞信号（冲突信号）

同一根蜡烛上同时出现 `enter_*` 与 `exit_*` 时，Freqtrade 视为冲突信号，默认不下单。处理方式：
1. 在 `populate_entry_trend` 中提前剔除满足退出条件的行
2. 实现 `confirm_trade_entry` 回调手动过滤

## 5. 止损、ROI 与仓位管理

| 参数 | 说明 |
|---|---|
| `stoploss` | 固定止损比例（负值），如 `-0.10` 表示亏损 10% 时强制平仓 |
| `minimal_roi` | ROI 字典，键为运行时间（秒），值为目标收益率。例如 `{"0": 0.01, "3600": 0.03}` 表示立即平仓 1%，持仓 1 小时后若收益 >=3% 再平 |
| `trailing_stop` | 启用追踪止损，配合 `trailing_stop_positive`、`trailing_stop_positive_offset` 使用 |
| `max_open_trades`（配置文件） | 同时最多持有的交易数量 |
| `startup_candle_count` | 策略启动所需的历史蜡烛数，确保所有指标都有有效值 |

> **最佳实践**：在回测前先使用 `freqtrade lookahead-analysis` 与 `freqtrade recursive-analysis` 检查 `startup_candle_count` 与指标前瞻性问题。

## 6. 策略回调函数（高级特性）

Freqtrade 允��在关键时刻插入自定义回调，实现更细粒度的控制：

| 回调函数 | 触发时机 | 常用场景 |
|---|---|---|
| `custom_trade_info` | 交易创建后 | 添加自定义标签、记录额外信息 |
| `confirm_trade_entry` | 生成入场信号前 | 根据外部因素（如风控、行情）决定是否执行入场 |
| `confirm_trade_exit` | 生成出场信号前 | 防止在高波动时误平仓 |
| `adjust_trade_position` | 持仓期间 | 动态修改止损、移动止盈或加仓 |

### 示例：限制每对最大持仓时间

```python
from datetime import timedelta

class MyStrategy(IStrategy):
    max_trade_duration = timedelta(hours=6)

    def confirm_trade_exit(self, pair, order, trade, **kwargs):
        if trade.close_date - trade.open_date > self.max_trade_duration:
            return True  # 触发平仓
        return False
```

## 8. 数据获取与生成

### 8.1 下载历史 K 线数据

```bash
freqtrade download-data \
    -c user_data/config.json \
    --exchange binance \
    --base BTC \
    --quote USDT \
    --timeframe 1h \
    --timerange 20220101-20230101
```

- `--timerange` 格式：`YYYYMMDD-YYYYMMDD`（左闭右开）
- 下载文件位于 `user_data/data/binance/BTC_USDT/1h/data_1h.csv`
- 格式：`timestamp,open,high,low,close,volume`
- 如网络受限，可添加 `--proxy http://127.0.0.1:7897`

### 8.2 生成随机 K 线数据（无需联网）

```python
import random, csv, datetime, os

pairs = [('binance', 'BTC/USDT')]
start = datetime.datetime(2022, 1, 1)
rows = []
price = 30000.0
for i in range(100):
    ts = start + datetime.timedelta(hours=i)
    open_ = price
    high = open_ * (1 + random.uniform(0, 0.01))
    low = open_ * (1 - random.uniform(0, 0.01))
    close = random.uniform(low, high)
    volume = random.uniform(10, 100)
    rows.append([int(ts.timestamp() * 1000), open_, high, low, close, volume])
    price = close

path = 'user_data/data/binance/BTC_USDT/1h'
os.makedirs(path, exist_ok=True)
with open(f'{path}/data_1h.csv', 'w', newline='') as f:
    writer = csv.writer(f)
    writer.writerow(['timestamp', 'open', 'high', 'low', 'close', 'volume'])
    writer.writerows(rows)
print(f'已写入 {path}/data_1h.csv')
```

## 9. 回测命令与导出选项

### 9.1 回测命令

```bash
freqtrade backtesting \
    -c user_data/config.json \
    --strategy MyStrategy \
    --timerange 20220101-20230101 \
    --timeframe 1h \
    --loglevel DEBUG \
    --export trades,plot,summary
```

### 9.2 参数说明

| 参数 | 说明 |
|------|------|
| `-c` | 配置文件路径 |
| `--strategy` | 策略类名（文件在 `user_data/strategies/`） |
| `--timerange` | 回测时间窗口 `YYYYMMDD-YYYYMMDD` |
| `--timeframe` | K 线周期，必须与数据匹配 |
| `--loglevel` | 建议 `DEBUG`，便于排查 |
| `--export` | 导出内容，可组合：`trades`、`plot`、`summary` |

### 9.3 导出选项详解

| 选项 | 输出文件 | 内容 |
|------|--------|------|
| `trades` | `trades.csv` | 每笔交易明细（时间、价格、手续费、盈亏等） |
| `plot` | `backtest_results.html` | 交互式可视化（累计收益曲线、每日收益分布、最大回撤） |
| `summary` | `summary.json` | 关键指标 JSON（`total_profit`, `sharpe_ratio`, `max_drawdown` 等） |

## 11. 回测结果分析

### 11.1 关键指标

| 指标 | 含义 | 判断依据 |
|------|------|----------|
| **累计净值** | 资金随时间的增长曲线 | 上升趋势 → 正向收益，波动大则风险高 |
| **最大回撤** (Max Drawdown) | 从峰值到谷底的最大跌幅 | 通常希望 < 20%，> 30% 需审视风控 |
| **夏普比率** (Sharpe Ratio) | 超额收益与波动率之比 | > 1 可接受，> 2 优秀 |
| **胜率** (Win Rate) | 盈利交易占比 | 高胜率需结合盈亏幅度 |
| **平均盈亏比** | 平均盈利与平均亏损之比 | > 1 表示盈亏比良好 |
| **收益回撤比** | 总收益与最大回撤之比 | > 2 较好，> 3 优秀 |

## 12. 常见问题排查

| 现象 | 可能原因 | 解决办法 |
|------|--------|--------|
| `No data found for pair …` | 数据目录或文件名错误 | 检查 `user_data/data/<exchange>/<pair>/<tf>/` 是否存在 |
| `Failed to parse timerange` | `--timerange` 格式不符 | 使用 `YYYYMMDD-YYYYMMDD`，无空格 |
| 回测异常慢（>5 分钟） | 数据量大 | 使用更粗的 `timeframe`（如 `4h`）或 `--processes N` |
| `AttributeError: 'DataFrame' object has no attribute …` | 某列未在 `populate_indicators` 中创建 | 在 `populate_indicators` 开头加入 `print(dataframe.head())` 检查列名 |
| `backtest_results.html` 未生成 | 未使用 `--export plot` | 添加 `--export plot` |
| 策略报错 `NaN` 导致信号缺失 | `startup_candle_count` 不足 | 设置合理的 `startup_candle_count`，或 `fillna(method='ffill')` |
| 冲突信号导致不下单 | 同一根蜡烛 enter + exit 同时满足 | 在 `populate_entry_trend` 加入互斥条件，或用 `confirm_trade_entry` 过滤 |
