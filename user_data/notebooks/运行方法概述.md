# Freqtrade 运行方法概述

本文档汇总了在本项目（/home/kali/Project/freqtrade）中常用的 **Freqtrade** 启动方式，帮助快速选择适合的运行方案。

---

## 1. 直接使用 CLI（本地 Python 环境）

> 适用于已在本机完成 `setup.sh` 安装，或在虚拟环境中手动安装的情况。

| 功能 | 常用命令 | 说明 |
|------|----------|------|
| 启动交易机器人 | `freqtrade trade --config config.json` | 读取配置文件后开始实时交易。
| 回测 | `freqtrade backtesting --config config.json --timerange 20210101-20211231` | 使用历史数据进行策略回测。
| 超参数优化 (Hyperopt) | `freqtrade hyperopt --config config.json --hyperopt-loss SharpeRiskRatioLoss` | 自动搜索最优参数组合。
| 生成报告 | `freqtrade plot-profit --config config.json`、`freqtrade plot-dataframe --config config.json` | 绘制收益、K 线等可视化报告。
| 运行 Web UI | `freqtrade webserver --api --config config.json` | 启动内置 Flask API 与前端 UI，默认 `http://127.0.0.1:8080`。

> **注意**：所有命令均可通过 `--help` 查看完整参数列表。

## 2. Docker/Docker‑Compose 方式

> 推荐新手或在不想手动配置依赖的环境中使用。项目根目录已提供 `docker-compose.yml`。

### 2.1 直接使用 Docker 镜像
```bash
# 拉取官方镜像（latest 为最新 stable 版）
docker pull ghcr.io/freqtrade/freqtrade:latest

# 运行容器（示例：使用本地 config 文件）
mkdir -p user_data && \
docker run -d \
  -v $(pwd)/user_data:/freqtrade/user_data \
  -v $(pwd)/config_examples/config_binance.example.json:/freqtrade/config.json \
  ghcr.io/freqtrade/freqtrade:latest trade
```

### 2.2 使用 docker‑compose（推荐）
```bash
# 启动全部服务（包括数据库、Web UI 等）
docker-compose up -d

# 查看日志
docker-compose logs -f
```

> `docker-compose.yml` 中已经预设了 `freqtrade`、`postgres`（可选）和 `jupyter` 等服务，直接 `docker-compose up` 即可。

## 3. Systemd 服务方式（生产环境）

> 将机器人注册为系统守护进程，系统重启后自动启动。

```bash
# 将提供的服务文件复制到 systemd 目录（已在项目根目录）
sudo cp freqtrade.service /etc/systemd/system/

# 编辑服务文件，确认 WorkingDirectory 与 ExecStart 路径正确
sudo nano /etc/systemd/system/freqtrade.service

# 重新加载 systemd 配置
sudo systemctl daemon-reload

# 启动并设为开机自启
sudo systemctl enable --now freqtrade.service

# 状态检查
systemctl status freqtrade.service
```

服务文件中主要字段说明：
- **WorkingDirectory**：Freqtrade 项目根目录
- **ExecStart**：`/usr/bin/env freqtrade trade --config /path/to/config.json`
- **Restart**：`on-failure`，确保异常退出时自动重启。

## 4. 通过 UI / API 交互

- **Web UI**：启动 `freqtrade webserver` 后，可在浏览器访问 `http://localhost:8080`，进行策略管理、交易监控、日志查看等。
- **REST API**：同样通过 `freqtrade webserver --api` 启动后，可使用 `curl` 或其他语言调用 `/api/v1/trades`、`/api/v1/strategies` 等端点，实现远程控制。

## 5. 常见运行场景对比

| 场景 | 推荐方式 | 关键优势 |
|------|----------|----------|
| 本地开发调试 | CLI + 虚拟环境 | 方便打断点、查看日志 |
| 快速部署（不想手动装依赖） | Docker‑Compose | 环境隔离、一次性启动全部组件 |
| 生产服务器长期运行 | Systemd + Docker（或裸 CLI） | 自动重启、统一管理 |
| 需要 UI 可视化 | Webserver | 直观的图形界面 |
| 大规模超参数搜索 | Docker + GPU 支持或本地 CLI（配合 `hyperopt`） | 资源弹性、并行化 |
