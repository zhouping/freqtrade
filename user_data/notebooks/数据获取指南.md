# 数据获取指南

本文档提供在 Freqtrade 项目中获取历史和实时数据的完整指南，涵盖以下三大类：

1. **历史 K 线数据**
2. **实时 K 线数据**
3. **实时交易数据**

---

## 1. 历史 K 线数据

### 1.1 支持的交易所与交易对

Freqtrade 使用 **CCXT** 库统一访问交易所。常用交易所配置已在 `config_examples` 中提供，例如 `config_binance.example.json`。在配置文件中指定 `exchange.name`（如 `binance`），并在 `pairlist` 中列出需要的交易对（如 `BTC/USDT`）。

### 1.2 参数说明

| 参数 | 说明 | 示例 |
|------|------|------|
| `exchange` | 交易所名称（对应 CCXT 支持的名称） | `binance` |
| `pair` | 交易对，格式 `BASE/QUOTE` | `BTC/USDT` |
| `timeframe` | K 线时间周期，支持 `1m`, `5m`, `1h`, `1d` 等 | `1h` |
| `timerange` | 下载的时间范围，格式 `YYYYMMDD-YYYYMMDD` 或 `YYYYMMDD`（单日）| `20230101-20231231` |
| `data_dir` | 数据保存目录，默认 `user_data/data/<exchange>/<pair>/<timeframe>/` |

### 1.3 下载方法

使用内置 CLI 命令 `freqtrade download-data`（或 `ft download-data`）下载历史 K 线数据。例如：

```bash
freqtrade download-data \
  --exchange binance \
  --pair BTC/USDT \
  --timeframe 1h \
  --timerange 20230101-20231231 \
  --data-dir /home/kali/Project/freqtrade/user_data/data
```

> **提示**：若需要一次性下载多个交易对或时间段，可使用 `--pairs` 参数并传入逗号分隔列表。

### 1.4 保存结构与格式

下载完成后，文件会存放在如下路径（以 Binance BTC/USDT 1h 为例）：
```
/home/kali/Project/freqtrade/user_data/data/binance/BTC_USDT/1h/
    ├─ 2023-01-01_2023-12-31.json
    └─ 2023-01-01_2023-12-31.parquet (可选)
```

- **JSON**：每根 K 线为一条记录，字段包括 `timestamp`, `open`, `high`, `low`, `close`, `volume`。
- **Parquet**（可通过 `--format parquet` 指定）：列式存储，适合大数据量分析。

### 1.5 常见问题

- **数据不完整**：检查网络是否中断，或交易所是否限制历史数据范围。可以分段下载（如每月一次）再合并。
- **时间对齐**：部分交易所的时间戳采用毫秒，需要自行除以 1000 转为秒。

## 2. 实时 K 线数据

### 2.1 参数

实时 K 线与历史下载相同，只是不指定 `timerange`，并使用 `--live` 标记让程序持续拉取。示例参数同上。

### 2.2 拉取方式

使用 `freqtrade download-data` 的 `--live` 选项，或直接使用 **WebSocket** 客户端脚本 `ws_client.py`。

#### 2.2.1 使用 CLI

```bash
freqtrade download-data \
  --exchange binance \
  --pair BTC/USDT \
  --timeframe 1m \
  --live \
  --data-dir /home/kali/Project/freqtrade/user_data/data
```

此命令会在后台持续写入最新的 K 线数据到同一目录下的最新文件（如 `live.json`），程序退出前请手动终止（Ctrl+C）。

#### 2.2.2 使用 WebSocket 脚本

`/home/kali/Project/freqtrade/scripts/ws_client.py` 已封装了 Binance、Bybit 等交易所的 WS 订阅。示例运行：

```bash
python scripts/ws_client.py \
  --exchange binance \
  --pair BTC/USDT \
  --timeframe 1m \
  --output /home/kali/Project/freqtrade/user_data/data/binance/BTC_USDT/1m/live.json
```

脚本会把每根新 K 线追加到 `live.json`，并在出现掉线时自动重连。

### 2.3 数据格式

- **JSON 行格式**（每行一个 JSON 对象），便于流式读取。
- 字段同历史数据，只是 `timestamp` 为最新的毫秒时间戳。

## 3. 实时交易数据

交易所的 **账户交易记录**（下单、成交、取消）只能通过 **私有 API** 获取，需要在 `config.json` 中配置 API Key/Secret 并开启 **authenticated** 权限。

### 3.1 参数

| 参数 | 说明 |
|------|------|
| `exchange` | 交易所名称 |
| `api_key` / `api_secret` | 账户凭证（放在 `config.json` 中的 `api_keys` 部分） |
| `user_id` | 部分交易所（如 Binance）无需额外用户 ID，使用 API Key 即可 |
| `timerange` | 需要查询的时间段，格式同上 |

### 3.2 下载方式

使用 `freqtrade download-data` 的 `--trade-data` 选项：

```bash
freqtrade download-data \
  --exchange binance \
  --trade-data \
  --timerange 20240101-20240415 \
  --data-dir /home/kali/Project/freqtrade/user_data/data
```

该命令会调用交易所的 **私有交易记录接口**，把成交记录保存为 `trades.json`（或 `parquet`）。

### 3.3 保存结构

```
/home/kali/Project/freqtrade/user_data/data/binance/trades/
    ├─ 2024-01-01_2024-04-15.json
    └─ 2024-01-01_2024-04-15.parquet
```

字段示例：
- `id`、`orderId`
- `symbol`
- `side`（buy/sell）
- `price`
- `amount`
- `timestamp`
- `fee`

### 3.4 注意事项

- **安全**：API Key 与 Secret **仅**保存在 `config.json`，请不要提交到 Git。可使用 `.gitignore` 排除 `config.json`。
- **速率限制**：交易所对私有接口有请求频率限制，建议一次性下载较大时间段后本地自行切分。
- **权限**：确保在交易所后台已启用 “Read Info & Trade” 权限，否则会返回 401 错误。
