# Freqtrade 现货 vs 期货配置对比

## 配置差异

|| 配置项 | 现货 (Spot) | 期货 (Futures) |
||--------|-------------|----------------|
| `trading_mode` | `"spot"` | `"futures"` |
| `margin_mode` | ❌ 无 | `"isolated"` |
| `pair_whitelist` | `["BTC/USDT"]` | `["BTC/USDT:USDT"]` |
| 数据目录 | `user_data/data/` | `user_data/data/futures/` |
| 数据文件名 | `BTC_USDT-5m.feather` | `BTCUSDT_USDT-5m-futures.feather` |
| 交易对格式 | `BTC/USDT` (有斜杠) | `BTC/USDT:USDT` (base/quote/margin) |
| 代理 | ✅ 需要 | ✅ 需要 |

## 关键经验

1. **代理必须能连上 Binance 主网** — 不需要 Testnet
2. **现货模式 + 现货数据** — 正确
3. **期货模式 + 期货数据** — 正确
4. **禁止混用** — 现货模式+期货数据 或 期货模式+现货数据 都是错误的

## 配置文件

### 现货配置: config_binance_spot.json

```json
{
  "exchange": {
    "name": "binance",
    "pair_whitelist": ["BTC/USDT"],
    "trading_mode": "spot"
  }
}
```

### 期货配置: config_binance_futures.json

```json
{
  "trading_mode": "futures",
  "margin_mode": "isolated",
  "exchange": {
    "name": "binance",
    "pair_whitelist": ["BTC/USDT:USDT"],
    "trading_mode": "futures",
    "futures_trading_mode": "perpetual"
  }
}
```

## 回测命令

```bash
cd /home/kali/Project/freqtrade

# 现货回测
export http_proxy=http://127.0.0.1:7897
export https_proxy=http://127.0.0.1:7897

freqtrade backtesting \
  --config user_data/config_binance_spot.json \
  --strategy GodStra \
  --timerange 20250101-20250107

# 期货回测
freqtrade backtesting \
  --config user_data/config_binance_futures.json \
  --strategy GodStra \
  --timerange 20250101-20250107
```
