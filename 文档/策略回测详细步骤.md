## 2. 创建用户目录 & 配置文件
```bash
# 第一次使用时创建用户目录，默认在 ./user_data/ 下
freqtrade create-userdir --userdir user_data
```
`user_data/` 结构示例：
```
user_data/
├─ data/                # 保存下载的 K 线 CSV
├─ strategies/          # 放置自定义策略文件 (*.py)
├─ logs/                # 运行日志
├─ backtest_results/   # 回测输出（html、csv 等）
└─ config.json          # 运行配置文件
```
### 配置文件
复制官方示例并打开 `dry_run`（防止真实下单）：
```bash
cp config_examples/config_binance.example.json user_data/config.json
sed -i 's/"dry_run": false/"dry_run": true/' user_data/config.json
```
必要时根据实际交易所修改 `exchange`, `key`, `secret` 等字段，回测时这些信息不被使用，仅用于配置结构完整性。

## 3. 下载历史 K 线数据（以 1 年 BTC/USDT 1h 为例）
```bash
freqtrade download-data \
    -c user_data/config.json \
    --exchange binance \
    --base BTC \
    --quote USDT \
    --timeframe 1h \
    --timerange 20220101-20230101
```
- `--timerange`：`YYYYMMDD-YYYYMMDD`（左闭右开），上述命令会下载 **2022‑01‑01 00:00** 到 **2023‑01‑01 00:00** 之间的全部 1h K 线。
- 下载完成后文件位于 `user_data/data/binance/BTC_USDT/1h/data_1h.csv`，格式为 `timestamp,open,high,low,close,volume`（UTC 时间戳）。
- 如网络受限，可添加 `--proxy http://127.0.0.1:1080` 或 `--disable-ssl` 参数。

> **注意**：若已有相同时间段的 CSV，命令会自动跳过已存在的行，仅追加缺失部分，保证增量下载安全。

## 4. 回测命令与关键参数
```bash
freqtrade backtesting \
    -c user_data/config.json \
    --strategy MyStrategy \
    --timerange 20220101-20230101 \
    --timeframe 1h \
    --loglevel DEBUG \
    --export trades,plot,summary
```
### 参数解释
| 参数 | 说明 |
|------|------|
| `-c` | 指向配置文件（上一步创建的 `user_data/config.json`）。 |
| `--strategy` | 要回测的策略类名（文件必须在 `user_data/strategies/` 中，类需继承 `IStrategy`）。 |
| `--timerange` | 回测时间窗口，使用同下载时的格式。 |
| `--timeframe` | K 线周期，必须与已下载的数据周期相匹配。 |
| `--loglevel` | 建议使用 `DEBUG`，便于错误排查。 |
| `--export` | 导出内容，可组合使用：<br>• `trades` – 生成 `trades.csv`（每笔交易明细）<br>• `plot` – 生成交互式 `backtest_results.html`（盈亏曲线、回撤、持仓等）<br>• `summary` – 生成 `summary.json`（收益、夏普、最大回撤等指标）。 |

> 若只想快速预览，可仅使用 `--export plot`，回测结束后在 `user_data/backtest_results/` 打开 `backtest_results.html` 即可。

---

## 5. 常用导出选项补充
- **`--export trades`**：每笔交易的 `open_date、close_date、open_rate、close_rate、profit、fee` 等字段，便于自行做进一步分析或导入 Excel。
- **`--export plot`**：默认生成交互式 HTML，包含累计收益曲线、每日收益分布、最大回撤点标记、持仓数量变化等可视化图表。
- **`--export summary`**：JSON 包含关键指标，如 `total_profit`, `profit_abs`, `max_drawdown`, `sharpe_ratio`, `sortino_ratio`, `trade_count` 等，适合自动化报告。
- **`--export csv`**（旧版本）：等同于 `trades`，若使用旧 CLI 仍可兼容。

## 7. 常见问题与调试技巧
| 现象 | 可能原因 | 解决方案 |
|------|----------|----------|
| `No data found for pair …` | 下载目录或文件命名错误 | 检查 `user_data/data/<exchange>/<pair>/<tf>/data_*.csv` 是否存在；确认 `config.json` 中 `exchange`、`pairlist` 与下载时保持一致。 |
| `Failed to parse timerange` | `--timerange` 格式不符合 `YYYYMMDD-YYYYMMDD` | 确认日期之间没有空格或非法字符，起始日期 ≤ 结束日期。 |
| 回测异常慢（数分钟以上） | 数据量大且未启用缓存 | 1) 用 `--timeframe` 调整为更粗的周期（如 `4h`）降低数据点数量；2) 在 `config.json` 开启 `sqlite` WAL 模式或使用 `--processes N`（实验性）提升读写并发。 |
| 策略报错 `AttributeError` | 某列未在 `populate_indicators` 中创建 | 在 `populate_indicators` 开头加入 `print(dataframe.head())` 检查列名；确保使用 `dataframe['close']` 等已有列。 |
| 找不到 `backtest_results.html` | 未使用 `--export plot` 或输出目录被误改 | 添加 `--export plot`，或手动检查 `user_data/backtest_results/`。 |

### 查看日志
```bash
cat user_data/logs/freqtrade.log | tail -n 50
```
日志中会记录每根 K 线的加载、指标计算、信号生成以及每笔交易的详细信息，定位错误时非常有帮助。

## 8. 小结（一步到位的完整脚本）
以下脚本把所有步骤串联，可直接复制运行（请根据实际交易对和时间自行修改变量）。
```bash
#!/usr/bin/env bash
set -e

PROJECT_ROOT="/home/kali/Project/freqtrade"
cd "$PROJECT_ROOT"
source .venv/bin/activate

# 1. 初始化用户目录（若已存在可省略）
freqtrade create-userdir --userdir user_data

# 2. 复制配置并开启 dry‑run
cp -n config_examples/config_binance.example.json user_data/config.json || true
sed -i 's/"dry_run": false/"dry_run": true/' user_data/config.json

# 3. 下载 1 年 BTC/USDT 1h 数据
freqtrade download-data \
    -c user_data/config.json \
    --exchange binance \
    --base BTC \
    --quote USDT \
    --timeframe 1h \
    --timerange 20220101-20230101

# 4. 回测自定义策略（请把 MyStrategy 放到 strategies/ 目录）
freqtrade backtesting \
    -c user_data/config.json \
    --strategy MyStrategy \
    --timerange 20220101-20230101 \
    --timeframe 1h \
    --loglevel DEBUG \
    --export trades,plot,summary

# 5. 打开可视化报告（可选）
xdg-open user_data/backtest_results/backtest_results.html
```
运行完毕后，`user_data/backtest_results/` 中即拥有完整的回测报告，可直接交付给业务或进一步分析。
